# P7 「瞬間組み立て」(文をつくる v2) 設計 — 2026-09-06

ユーザー決定(2026-09-06): 3 段階に作り直す / 外れたらヒントで言い直させる / 文の中身を自分の生活に合わせる。
旧「文をつくる」(MixingPage / useMixingSession)は置き換える(ユーザー承認済み)。deal / combinations / particles は再利用する。

## 1. 根拠(設計書 18 章の要約)
- 自動化は練習した処理にしか進まない(DeKeyser 1997)。弱点=「日本語の意味 → 文を瞬時に組む」なので、その処理を直接鍛える。
- 言い直し(リキャスト)より、学習者にもう一度言わせるプロンプトの方が効果が大きい(Lyster & Saito 2010)。
- 同じ内容の繰り返しで流暢さが定着する(de Jong & Perfetti 2011)。文型は混ぜて出す(Nakata & Suzuki 2019)。
- 効く練習の条件: 具体的な目標・即時フィードバック・繰り返し・正答率 85% 前後・進捗の記録(TESL-EJ 2025)。
- 自分で内容を選び相手に理解される必要がある練習は翌日の伸びが大きい(Serfaty 2026)。自分に関する文は記憶に残る(自己参照効果)。

## 2. 3 段階
### 段階 1「型を回す」(Gemini なし)
- 1 セッション = 3 つの型 × 4 組 = 12 項目 × 2 周(2 周目は同じ 12 項目を並べ替え、目標時間を短く)。
- 型の選び方: level ≤ 設定レベル、習熟(初回正答率・応答の速さ)が低い順。組の語は「自分の語」を優先し、未経験の組を優先。3 つの型は A B C A B C … と交互に出す。
- 1 項目の流れ: 日本語の合図(表示+読み上げ) → 録音(合図終了で自動開始、話し終えたらタップで停止) → 聞こえた文を模範と照合(scorePronunciation、含有または類似度 0.8)。
  - 一致: 「言えた」+ 応答までの時間(合図の終わりから声の出だしまで)。
  - 不一致: まず**ヒント**(「『to』が抜けています。もう一度」/「『How do I』から言ってみましょう」)で 1 回だけ再挑戦 → それでも不一致なら模範を文字と音で見せる。「間違い」とは言わない。
- 記録: mixing_progress に 初回一致数 / ヒント使用数 / 応答時間の合計と回数 を追加。型ごとの習熟 = 直近の初回一致率 ≥ 85% かつ 応答時間の中央値 ≤ 2.5 秒(8 回以上)で「習熟」。全型が習熟したら次のレベルを提案。

### 段階 2「お題で言う」(Gemini 2 回)
- 日本語のお題だけ(例:「週末の予定を 2 文で」「{推し}について 1 文」)。お題は content/{lang}/topics.json から、自分の語で穴埋め。
- 流れ: お題 → 話す → Gemini が「通じたか・自然な言い方・**続きの質問**(相手が知らない情報を聞く)」を返す → 続きの質問に答える → もう一度判定。伝わらないと会話が進まない形にする。
- 表示: 聞こえた文 / 通じたか / 自然な言い方(文字+音、日本語訳) / 相手の質問。

### 段階 3「即答」(Gemini 2 回)
- その日の型と自分の語から Gemini が短い質問を 8 つ作る(1 日 1 回、localStorage にキャッシュ)。
- 同じ 8 問を 3 周。目標の応答時間は 3 秒 → 2 秒 → 1.5 秒。各答えの応答時間を記録。
- 3 周後に 1 回だけ Gemini が全 24 答をまとめて判定(通じたか+より自然な一言)。まとめ画面で「1 周目 2.4 秒 → 3 周目 1.3 秒」のように前の自分と比べる。
- 記録: speaking_sessions(kind='quick') に周ごとの平均応答時間と通じた率。

## 3. 自分の語(personalWords)
- 設定に `personalWords: { ja, en, ko, kind: 'place'|'person'|'thing'|'media' }[]` を追加(この端末に保存)。
- 設定画面: 日本語と種類を入れて「翻訳して追加」(Gemini が en/ko を埋める。編集・削除可)。
- 段階 1 の名詞スロット(kind 一致)、段階 2 のお題の穴埋め、段階 3 の質問生成に混ぜる。絵文字は種類ごとの既定(📍 👤 📦 🎬)。

## 4. 応答時間の測り方
- SttResult に `onsetMs`(録音開始から声の出だしまで)を追加。Gemini 経路は録音サンプルの先頭無音長から、Web Speech 経路は最初の結果イベントまでの時間から算出。
- 応答時間 = 合図の読み上げ終了 → 録音開始 の遅れ + onsetMs。

## 5. 画面
- /mixing は 3 つのタブ「型を回す」「お題で言う」「即答」。練習一覧の名前を「瞬間組み立て」に。
- 訂正の赤ペンは出さない(ヒントと模範だけ)。数字は 応答時間 と 言えた数 だけ。
